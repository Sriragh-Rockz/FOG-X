# 🌫️ FOG-X

### Interactive Camera-Based Fog & Hand Gesture Experience

FOG-X is an interactive web experience that transforms your camera into a virtual fogged mirror.

Users can create fog by blowing toward the camera and interact with the fog using hand gestures.

---

## ✨ Features

- 📷 Real-time camera interaction
- 💨 Blow detection using facial landmarks
- 🌫️ Dynamic fog generation
- ☝️ Index-finger writing interaction
- 🖐️ Five-finger palm rubbing
- ✊ Closed-hand gesture does nothing
- 🎨 Interactive fog surface
- ⚡ Real-time hand tracking
- 🌐 Runs directly in a web browser

---

## 🎮 How to Use

1. Open the FOG-X website.
2. Allow camera permission.
3. Click **ENTER**.
4. Blow toward the camera to generate fog.
5. ☝️ Extend your index finger to write on the fog.
6. 🖐️ Open all five fingers and move your palm over the fog to rub/clear a local area.
7. ✊ Close your hand to stop interaction.
8. Blow again to create fresh fog.
